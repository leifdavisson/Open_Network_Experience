USER IMPACT:
  When an operator or automated testing script triggers "▶ Run Diagnostic On Sensor" without having chosen an online sensor, the application invokes a synchronous browser native `alert('Please select an online sensor from the dropdown first.')`. This blocks the main thread, prevents background polling cycles while open, and can cause automated headless testing harnesses to hang if dialog handlers are not registered. Furthermore, users must manually select from the dropdown every time rather than having the system intelligently pre-select the primary online sensor.

---

## SUMMARY
The Live Diagnostics Action Center (`#view-monitor-ondemand`) executes synthetic network probes cleanly across all 17 protocols and renders structured latency and console output upon valid execution. However, validation handling on empty sensor submission relies on a blocking native `alert()` modal inside `sensors.js:917`. Replacing this with an inline non-blocking feedback message or inline banner, combined with pre-selecting the first available online sensor, will streamline NOC operations.

---

## REPRODUCTION STEPS
1. Open http://10.98.2.125:8000/ in a browser.
2. Click **Live Diagnostics** (`#nav-monitor-ondemand`) in the sidebar navigation.
3. Leave "1. Target Edge Sensor" on its default blank selection ("Select an online sensor...").
4. Click **"▶ Run Diagnostic On Sensor"** (`#btn-run-diag`).
5. Observe the synchronous modal dialog `alert()` blocking page interaction.

## EXPECTED RESULT
The form should display an inline validation error below `#diag-sensor-select` (e.g. using `showFormError` or red border highlighting), or the dropdown should automatically default to the first active online sensor upon view initialization.

## ACTUAL RESULT
The browser pops up a synchronous window alert dialog (`alert('Please select an online sensor from the dropdown first.')`).

## ROOT CAUSE & RECOMMENDATION

### Code Location Hint
- Primary: [`server/static/js/modules/sensors.js`](file:///data/Open_Network_Experience/server/static/js/modules/sensors.js#L916-L919)
```javascript
if (!sensorId) {
    alert('Please select an online sensor from the dropdown first.');
    return;
}
```

### Recommended Fix
1. Replace native `alert()` with an inline validation notification:
   ```javascript
   if (!sensorId) {
       showFormError('diag-sensor-select', 'Please select an online sensor from the dropdown first.');
       return;
   }
   ```
2. In `renderDashboard()`, automatically select the first online sensor if none is currently chosen:
   ```javascript
   const diagSelect = document.getElementById('diag-sensor-select');
   if (diagSelect && !diagSelect.value && diagSelectOptions.length > 1) {
       diagSelect.selectedIndex = 1;
   }
   ```
