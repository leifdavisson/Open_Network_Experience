## 2025-09-04 - Global Modal Escape Handlers & Focus Indicators
**Learning:** In dynamically updated dashboards with multiple modals spawned by inline JS or table action buttons, individual modal close handlers can easily be omitted from central keyboard listeners (`Escape` key), creating keyboard traps for screen reader or power users. Additionally, dark-themed custom UI controls require explicit `:focus-visible` styling using design CSS variables (`var(--accent)`) to ensure high contrast focus rings during tab navigation.
**Action:** When adding new modals to `dashboard.html`, always register their `closeModal()` functions in the global `document.addEventListener('keydown')` block alongside existing modal close handlers and ensure `:focus-visible` rules are defined globally.
