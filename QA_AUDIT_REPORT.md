# ONE Platform UI/UX Audit & Functional Test Report

| Severity | Component | Persona | Issue Description | Steps to Reproduce | Recommended Fix |
|---|---|---|---|---|---|
| **High** | Sensor Setup Wizard (`options.js`) | Admin | **Silent State Corruption (Empty Configs):** Submitting an empty value for the probe interval saves `NaN` directly to the local extension config, breaking the background telemetry loops silently. | 1. Open Chromebook Extension Settings.<br>2. Clear the "Probe Interval" input field.<br>3. Click Save.<br>4. Re-open to observe `NaN` saved. | Implement input validation and fallbacks in `options.js`: `parseInt(form.elements['probe_interval_seconds'].value, 10) || 300` and display a warning if empty. |
| **Medium** | Admin Dashboard (`sensors.js` GIS Map) | Admin | **Broken Map Rendering (Window Resize):** The Leaflet map instances (`mapInstance` and `wallboardMapInstance`) do not listen to global window resize events, causing gray tile overlaps and broken bounds. | 1. Navigate to the GIS Campus Map view.<br>2. Resize the browser window or rotate the device.<br>3. Observe broken map rendering until forced to redraw. | Add a global event listener in `sensors.js` or `main.js`: `window.addEventListener('resize', () => { if(mapInstance) mapInstance.invalidateSize(); })`. |
| **Medium** | Admin Dashboard (Probe Setup Wizard) | Admin | **Missing Frontend Validation:** The EasyBuilder Custom Probe modal allows submitting completely empty target and name fields, pushing malformed data to the backend. | 1. Open "+ Create Custom Probe" modal.<br>2. Leave "Probe Name" and "Target" blank.<br>3. Click Save.<br>4. Observe a nameless probe is created. | Add HTML5 `required` attributes to the input fields and add `if (!name || !target) return showFormError();` in `handleSaveProbe`. |
| **Low** | Admin Dashboard (Quick Actions) | Admin | **Missing Debounce on Quick Actions:** While the main diagnostic modal has button disabling, the inline table Quick Actions (e.g., `triggerPcap`, `launchSensorDiag`) do not debounce clicks, allowing rapid-fire duplicate API requests. | 1. Open the Sensors or Alerts table.<br>2. Rapidly double-click the "⚡ PCAP" or "🔬 Diag" buttons.<br>3. Observe duplicate POST requests in the Network tab. | Disable the button via `e.target.disabled = true` within the inline `onclick` handler, or implement a global debouncer for table actions. |
| **UX Suggestion** | Admin Dashboard (Grafana Sub-Scroller) | Admin | **Iframe Thrashing on Rapid Clicks:** Rapidly clicking through the Grafana sub-navigation tabs (e.g., NOC Overview, CAASPP Readiness) forces the iframe to rapidly reload the heavy Grafana dashboards, causing browser stutter. | 1. Navigate to the Grafana auto-scroller slide.<br>2. Click the 4 sub-nav pills rapidly back and forth.<br>3. Observe browser UI lockup and heavy network load. | Add a short 300ms debounce/timeout before setting `iframe.src` in `goToGrafanaSub` to prevent iframe thrashing if the user is just clicking through. |
